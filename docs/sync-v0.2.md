# v0.2 登录、同步与备份

决策日期：2026-10-18。需求依据：`task-matrix-requirements.md` v1.6。

## 使用流程

游客无需登录，继续使用原 `yaoshitu` IndexedDB。设置页的 GitHub 登录会进入独立账号空间；不会自动上传游客任务。用户可明确选择“导入本机游客数据”，复制任务和笔记（含归档、回收站）并上传，原数据保留。重复导入生成副本。

退出账号返回游客空间，账号的本地数据和待上传队列保留；再次登录同一账号继续。服务地址与用户 ID 共同确定数据库名；换账号不复用数据或队列。其他标签页观察到账号变化会重新加载，避免旧表单误写。

## 协议与一致性

- `SyncTransport` 隔离 PocketBase SDK；业务模型和本地队列不绑定 SDK。
- 任务、笔记、默认视图参与同步。示例数据标记、上次备份时间、会话、队列和设备信息不上传。
- 每次本地业务写入和 outbox 入队在同一个 Dexie 事务中提交。操作有唯一 ID、严格递增的本地队列顺序、基准版本与字段补丁。
- `POST /api/yaoshitu/push` 在服务器事务中校验账号、字段、版本，合并数据并记录操作回执。重复请求不重复写；版本不符返回 409 和最新文档，客户端保留本地补丁再试。
- 服务器为每条文档及修改字段分配版本，不使用客户端时间排序。不同字段分别合并；同字段按服务器接受顺序生效，保留最多最近 100 个被替代的冲突字段旧值（历史 JSON 总长度上限 2,000,000），可在设置页恢复。该策略不承诺同字段修改全部同时生效。
- 紧急/重要坐标为 `position` 整体，完成状态/完成时间为 `completion` 整体；标签、依赖、时间记录数组目前整体合并，不按数组元素协作合并。
- `GET /api/yaoshitu/pull` 按 key 分页读取全量文档，避免设备时钟与游标混用。收到远端文档后叠加尚未上传的本地补丁。首版选择可审计的全量拉取，不声称大规模增量同步性能已验证。
- SSE 仅触发补拉，消息不携带业务正文。联网恢复、页面聚焦、修改后 800ms 防抖和页面运行期间每 15 秒检查提供兜底；失败指数退避至最多 5 分钟，队列不因次数耗尽而删除。页面关闭时不承诺后台同步。
- 单次网络请求 20 秒超时；OAuth 2 分钟超时。有效登录接近过期时尝试刷新；过期后重新 GitHub 登录，本地修改继续保留。
- 若灾难恢复导致服务器版本比本机已知版本更低，停止自动推送并提示先导出本地备份，由管理员协调恢复；首版不自动丢弃本机高版本或盲目覆盖回退后的服务端。

## 删除与账号生命周期

任务和笔记均软删除。账号空间由服务器确定删除时间，每小时清理超过 30 天的内容；推送时也检查过期。清理后保留最小文档 key 与永久删除标志，丢弃正文和冲突旧值，旧离线编辑不能复活该 ID。账号删除时这些最小标记也随账号清理。

游客仍在本机启动时清理过期回收站。账号注销删除在线账号、全部关联文档与回执，以及当前浏览器的账号数据库；其他设备离线副本无法远程抹除。服务器历史备份按保留周期过期，正式环境应限制为明确的周期，不能承诺注销瞬间抹除所有历史备份。

## 备份与加密边界

完整 JSON 备份继续使用 formatVersion 1，可读取旧版合法信封；新增笔记 deletedAt 为可选字段。导入前校验任务、笔记、版本及设置，并剔除未知字段；账号与同步凭据不进入备份。账号只能合并为副本，游客可明确选择覆盖恢复。合并重映射 parentId/dependencies，不引用未导入的外部任务。

PocketBase 自动服务器快照默认每天 03:00（容器默认 UTC）生成，保留最近 7 份。异地 S3 备份必须部署时配置；仅本机快照不能抵御服务器磁盘故障。数据密钥与设置密钥须独立于数据库备份。

业务文档（含冲突旧值）整体 AES 加密后写 SQLite，解密仅在认证后的自定义接口中进行；元数据 owner/key、操作回执不加密。缺少数据密钥时服务拒绝启动。服务端持钥，不是端到端加密；浏览器 IndexedDB 和用户 JSON 默认不加密。生产 HTTPS 由 Caddy 提供。

## 验证状态

本机 PocketBase 0.40.5 已验证：全新数据库迁移、未登录拒绝、账号隔离、锁定原始写入 API、SSE 通知、操作幂等、版本冲突、不同字段合并、同字段旧值保留、服务端删除时间、永久删除防复活、注销级联、SQLite 正文非明文、服务器快照生成。将快照解压到新数据目录并启动独立实例后，已验证可使用独立保存的数据密钥恢复和解密原任务。

前端自动化覆盖本地事务回滚、账号空间隔离、队列重开持久化、远端合并保留待上传字段、永久删除屏蔽旧编辑、模拟断网重试和切换账号。手工验证设置页、登录失败提示、游客任务操作、笔记回收站与备份入口。

仍需正式部署验证：真实 GitHub 授权成功回调、实际两台设备与浏览器离线恢复、Ubuntu Docker 镜像运行、域名 TLS、异地备份配置与恢复。不得把本机测试视为这些项目已通过。独立“同步历史”视图仍为后续项，当前提供同步状态、待上传数与冲突恢复。
