## 二、Slogan 体系

### 主 Slogan（已定稿 v1.3）

| 语言 | Slogan |
|---|---|
| 中文 | 要事一图，轻重自现。 |
| 英文 | What matters, mapped. |

**解读**：
- 中文「轻重自现」对应产品差异化点——连续坐标（不是布尔四象限），任务的轻重程度在图上一目了然
- 英文「mapped」是双关：既是"被映射到坐标"，也是"被厘清了"

用于强调与传统 todo list 的差异化定位。

## 三、LOGO 系统

### 概念（来自 v1.3 品牌定稿）

> 坐标十字 + 一颗实心「要事」点 + 淡虚任务点

三个元素的语义：
- **坐标十字**：紧急 × 重要 两个轴，产品的核心差异化（连续坐标系）
- **实心「要事」点**：当前选中 / 最重要的任务，唯一焦点
- **淡虚任务点**：其他任务，弱化为噪声，反衬焦点

### 三方案对比

#### 方案 A · 十字焦点（推荐主标）

- 元素：坐标十字 + 1 颗实心紫点 + 4 颗空心灰点
- 语义：最忠于概念，"很多任务中选一个要事"的对比关系最完整
- 用途：app icon、官网主标、README header、社交头像

#### 方案 B · 焦点定位（推荐辅助标）

- 元素：坐标十字 + 1 颗实心紫点
- 语义：极简，去掉所有噪声
- 用途：favicon（16×16 起步）、状态栏图标、加载占位、命令面板图标

#### 方案 C · 象限投影（备选）

- 元素：坐标十字 + 右上象限淡紫填充 + 1 颗实心紫点
- 语义：把"四象限投影"这个二级视图概念也带进 LOGO
- 用途：教育场景、文档配图、二期能力介绍页
- 取舍：信息密度高，但小尺寸下象限填充容易糊，**不建议作主标**

### Wordmark 组合（推荐用 A）

```
[LOGO]  要事图
[LOGO]  Yaoshitu
[LOGO]  要事图 / Yaoshitu   ← 完整 wordmark，官网 header 用
```

字号比例：LOGO 高度 ≈ 字高 1.0×，LOGO 与文字间距 = LOGO 宽度的 0.25×。

## 四、品牌色

| 用途 | 色值 | 角色 |
|---|---|---|
| 主色（焦点） | `#534AB7` (purple 600) | 实心点、唯一强调色，全产品只此一个高饱和色 |
| 主色暗 | `#3C3489` (purple 800) | wordmark 文字、标题 |
| 主色淡 | `#EEEDFE` (purple 50) | 象限淡填、选中态背景 |
| 辅色 | `#888780` (gray 400) | 坐标轴、虚点、次要描边 |
| 卡片底 | `#F1EFE8` (gray 50) | LOGO 卡片背景、面板背景 |
| 文字主 | `#2C2C2A` (gray 900) | 正文 |
| 文字辅 | `#5F5E5A` (gray 600) | 说明文字、副标题 |
| 边框 | `#B4B2A9` (gray 200) | 卡片边框、分隔线 |

**色彩纪律**：
- 全产品只允许一个高饱和色（purple 600），其它一律灰阶
- 禁止使用红绿表意（a11y 反例）—— 重要紧急区不用红色，用 purple 深浅区分
- 四象限分区用「位置 + 灰阶」双重编码，不依赖色相（v1.4 非功能要求）

## 五、字体

| 用途 | 中文 | 英文 | 数字 |
|---|---|---|---|
| 界面 / 正文 | 思源黑体 / Source Han Sans | Inter | — |
| 标题 | 思源黑体 Medium | Inter Medium | — |
| 坐标值 / 代码 | — | — | JetBrains Mono |

理由：
- 思源黑体 + Inter 都是开源字体，与产品开源调性一致
- Inter 与 GitHub / Vercel 等开发者工具同源，目标用户熟悉
- JetBrains Mono 用于坐标系坐标值（如 `紧急 75 · 重要 88`），强化"坐标"语义

## 六、LOGO 使用规范

### 安全空间

LOGO 四周留白 = LOGO 高度的 1/4。安全空间内不允许放任何其他元素。

### 最小尺寸

| 用途 | 最小尺寸 |
|---|---|
| Favicon | 16×16（用方案 B） |
| 状态栏图标 | 20×20（用方案 B） |
| 完整 LOGO | 24×24（用方案 A） |
| Wordmark | LOGO 高度 ≥ 24px |

### 禁用

- 禁止渐变、阴影、发光、模糊（与产品"性能优先、不花哨"调性一致）
- 禁止旋转、拉伸、改比例
- 禁止替换主色（purple 600）为其他高饱和色
- 禁止在 LOGO 上叠文字或图标

### 反白场景（深色背景）

- 实心点：紫色 → 白色（`#FFFFFF`）
- 坐标十字：灰色 → `rgba(255,255,255,0.5)`
- 虚点：灰色描边 → `rgba(255,255,255,0.4)` 描边
- 卡片底：移除或改为 `rgba(255,255,255,0.05)`

### 单色印刷

- 实心点：100% 黑
- 其他元素：30% 黑
- 卡片底：移除
